# NetVolt Security — Landing page

Página web de NetVolt Security (seguridad electrónica, instalaciones eléctricas y soporte informático).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `netvolt-security`).
2. Sube **todo el contenido de esta carpeta** (`index.html` y la carpeta `assets`) a la raíz del repositorio.
3. En el repositorio ve a **Settings → Pages**.
4. En *Source* elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
5. En 1–2 minutos la página estará en `https://TU-USUARIO.github.io/netvolt-security/`.

## Contenido
- `index.html` — la página completa (HTML + CSS, sin dependencias que instalar).
- `assets/` — logo, fotos de trabajos, fotos de servicios y video.

Las fotos de la sección de servicios provienen de Unsplash (licencia gratuita de uso comercial).
